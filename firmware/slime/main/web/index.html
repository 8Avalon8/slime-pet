AI 设置

语音合成：小米 MiMo 填 https://api.xiaomimimo.com/v1，模型 mimo-v2.5-tts（音色 冰糖、茉莉、苏打、白桦），或 mimo-v2.5-tts-voicedesign（音色一栏写一句声音描述）；硅基流动填 https://api.siliconflow.cn/v1，默认 CosyVoice2，音色 bella、anna、claire、diana 等；其他 OpenAI 兼容的 /audio/speech 接口也行。
AI 点评、主动陪伴和语音对话用的模型接口（OpenAI 兼容）。这些只是存在史莱姆里，电脑上的 slime_hook.py 和 slime_buddy.py 会来读；电脑上设置了 SLIME_LLM_URL 等环境变量时以环境变量为准。API Key 保存后不会再显示，在局域网里是明文传输的，和 Wi-Fi 密码一样只在信得过的网络里填。改了接口地址而没有重新填 Key，原来的 Key 会被清掉。

WI-FI

切换网络后本页会断开，到新网络里打开 http://slime.local 。面板没有登录保护，只在局域网内使用。
