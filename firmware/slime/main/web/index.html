常用

功能演示约 2 分钟，开始前有 3 秒倒数。演示中长按屏幕可以提前结束。勿扰开始和结束设成同一个钟点就是关闭夜间勿扰。

让史莱姆演一下

手动切换的状态会保持 15 秒，并播放对应的音效（如果开着）。

音乐试听

设备合成的 8-bit 音效与小曲（乐谱在 main/tunes_original.h，可以换成自己的）。背景音乐会被任何音效打断。

自制音效（sfxr）

每点一次生成按钮都会随机出一个新音效并立刻播放。想精调可以去 sfxr.me（jsfxr）调好，再把导出的 JSON 贴进来。替换后的音效存在设备里，重启也在。

WI-FI

切换网络后本页会断开，到新网络里打开 http://slime.local 。面板没有登录保护，只在局域网内使用。
